# Particle Photo Assembly

Красивый эффект «пыли», которая собирается в фотографию.

Мелкие цветные частицы (как пылинки) сначала разбросаны, затем плавно формируют портрет.

## Демо

Открой `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).

Или используй GitHub Pages (если включишь).

## Управление

- **Собрать** — частицы летят на свои места и собирают фото
- **Разлететься** — частицы разлетаются в стороны
- **Заново** — полный перезапуск анимации
- **Клик по canvas** — локально «взрывает» частицы вокруг курсора

## Технологии

- Чистый HTML5 Canvas + Vanilla JS
- Без внешних зависимостей
- Адаптивный размер
- ~4000 частиц для детализации

## Как использовать своё фото

1. Замени base64 в `img.src` на своё изображение  
   или  
2. Измени код так, чтобы загружать файл через `<input type="file">`.

Сделано с любовью.
