# Particle Photo Assembly

Красивый эффект «пыли», которая собирается в фотографию.

Мелкие цветные частицы (как пылинки) сначала разбросаны, затем плавно формируют портрет.

## Как пользоваться

1. Открой `index.html` в браузере (или через GitHub Pages).
2. Нажми **«Выбрать фото»** и загрузи фотографию девушки.
3. Частицы автоматически разлетятся и соберутся в фото.

### Кнопки
- **Собрать** — частицы летят на свои места
- **Разлететься** — частицы разлетаются
- **Заново** — полный перезапуск
- **Клик по картинке** — локальный «взрыв» частиц

## Технологии
- Чистый HTML5 Canvas + Vanilla JS
- Без зависимостей
- ~4000 частиц
- Работает оффлайн
